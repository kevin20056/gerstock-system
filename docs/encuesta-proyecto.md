PREGUNTAS DE PROYECTO

1. ¿Qué proceso dentro de una empresa considera que toma más tiempo?

RESPUESTA:
Uno de los procesos que puede tomar más tiempo es la asignación y organización de tareas entre los empleados.

El sistema permitiría asignar tareas a personas específicas para evitar cruces o duplicación de trabajo.

También busca controlar los elementos disponibles en el inventario, evitando que dos trabajadores intenten utilizar o asignar el mismo elemento cuando solo existe una unidad.

El software sería versátil y podría utilizarse en diferentes tipos de empresas, independientemente de los productos o elementos que manejen.

El gerente o administrador sería quien registre productos, cantidades, precios, valores y realice modificaciones o eliminaciones.

La idea es desarrollar una plantilla de software reutilizable que pueda adaptarse a diferentes empresas sin tener que crear un sistema completamente diferente desde cero.

Cada empresa podría manejar su propia información, productos y configuración dentro del sistema.

2. ¿Cómo cree usted que funciona un software de inventario en una empresa?

RESPUESTA:
La empresa actualmente maneja un inventario limitado, principalmente de monitores y torres, sin controlar elementos pequeños como mouse o discos.

Cuando se realiza un movimiento de equipos, el trabajador envía un correo y el coordinador del área es quien actualiza el inventario.

El proceso de actualización no es automático y depende de una persona encargada.

La empresa maneja el material de diferentes formas, incluyendo el control de entradas y salidas.

También es necesario hacer seguimiento a los elementos para saber cuántos ingresaron, cuántos se entregaron y a quién fueron asignados.

Esto evidencia la necesidad de registrar los movimientos y mantener actualizado el inventario sin depender únicamente de correos o actualizaciones manuales.

3. ¿Qué problemas pueden ocurrir cuando varias personas manejan la misma información?

RESPUESTA:
Cuando varias personas manejan la misma información pueden ocurrir errores, especialmente cuando los empleados mueven o intercambian equipos sin actualizar el registro.

Un problema frecuente es que un trabajador cambie un computador o monitor de puesto y no informe el movimiento.

Esto provoca que la información del inventario no coincida con la ubicación real de los equipos.

En auditorías de una zona franca, la empresa debe demostrar que sus activos se encuentran físicamente donde están registrados.

Actualmente, para verificarlo, deben hacer una revisión puesto por puesto utilizando Excel y comparando la información registrada con los equipos físicos.

Si un equipo no aparece donde debería, puede generar problemas y posibles sanciones para la empresa.

Por esta razón, el software debería permitir llevar un registro actualizado de cada equipo, su ubicación y sus movimientos, dejando trazabilidad de quién realizó cada cambio.

4. ¿Cómo se suelen calcular actualmente los costos para fabricar un producto?

RESPUESTA:
El software no solo manejaría inventario, sino también el cálculo de costos de fabricación o producción.

La idea es que permita saber cuánto cuesta producir un determinado producto.

Para calcularlo, podría tener en cuenta elementos como materiales, recursos y otros costos asociados.

Esto sería útil, por ejemplo, en empresas dedicadas a la instalación o creación de redes, donde se utilizan diferentes materiales y recursos.

De esta manera, el sistema permitiría conocer el costo total de un trabajo o producto y facilitar el control de los costos de producción.

5. ¿Qué información cree que debería estar disponible rápidamente?

RESPUESTA:
La información que debería estar disponible rápidamente para tomar decisiones sería principalmente:

* Cantidad de material disponible en inventario.
* Costos de los materiales.
* Existencias actuales para saber si es necesario comprar o reponer materiales.
* Información actualizada para conocer cuánto hay y cuánto cuesta.
